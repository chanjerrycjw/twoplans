在 iPhone 上怎么用（越狱机也适用）

  1. 把 两个计划-iOS.html 传到手机 —— 隔空投送 / 微信文件传输助手 / Filza 都行。
  2. 用 Safari 打开它（必须是 Safari，Chrome 不能添加到主屏幕）。
  3. 点底部分享按钮 → 添加到主屏幕 → 右上角「添加」。
  4. 桌面出现紫色图标「两个计划」，点开就是全屏、无地址栏、离线可用的 App。
  5. 数据存在 Safari 本地，不联网；换机时用计划页里的「导出进度 / 导入进度」搬运。

想要真的 .ipa？

同一个目录下的 ios/ 里有一份完整的 SwiftUI 工程（两个计划 App）+ GitHub Actions 自动打包配置，可以在云端编出未签名的 ipa，越狱机用 TrollStore / AppSync 装。详见 ios/TwoPlans/README.md。

注意：iOS 原生二进制只能在 macOS + Xcode 上编译，Windows 本机编不了，所以走云编译。
